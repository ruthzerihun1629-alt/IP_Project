# Vehicle Rental Management System

## Project Description

The Vehicle Rental Management System is a web-based project designed to make vehicle rental easier and more convenient. It provides customers with a platform to explore available vehicles, learn about the rental service, and access account and booking-related pages.

The system aims to simplify the vehicle rental process by providing an organized and user-friendly interface.

## Project Features

- Homepage introducing the vehicle rental service.
- Vehicle page displaying available vehicles.
- About page providing information about the service.
- Contact page for customer inquiries.
- Login page for existing users.
- Registration page for new users.

## How to Run the Project

1. Clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation links.

## Version Control and Collaboration

The project is managed using  GitHub. Each team member works on an individual branch and submits a Pull Request for review before their changes are merged into the main branch.
